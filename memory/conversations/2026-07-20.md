## 1. Create the Python script

Create a file called `hi.py` somewhere that’s on your `$PATH` (or in a directory you’ll later add to `$PATH`). A good place is `~/.local/bin/`.

```bash
mkdir -p ~/.local/bin
touch ~/.local/bin/hi.py
chmod +x ~/.local/bin/hi.py
```

Edit `hi.py` with your favorite editor:

```python
#!/usr/bin/env python3
"""
hi – a tiny everyday assistant

Features:
  • Greets you with a friendly message.
  • Shows the current date & time.
  • Prints a random tip (optional).

Usage:
  $ hi            # default greeting
  $ hi --time     # show current time
  $ hi --tip      # show a random tip
  $ hi --help     # this help message
"""

import argparse
import datetime
import random
import sys

# A tiny collection of random tips (feel free to add more!)
TIPS = [
    "Take a short walk every hour to stay refreshed.",
    "Drink water regularly – aim for 8 cups a day.",
    "Prioritize tasks using the Eisenhower matrix.",
    "Set a timer for 25‑minute work blocks (Pomodoro).",
    "Keep your workspace clutter‑free for better focus."
]

def greet():
    """Print a friendly greeting."""
    print("👋 Hi! I'm your simple assistant. How can I help you today?")

def show_time():
    """Print the current local date and time."""
    now = datetime.datetime.now()
    print(f"🕒 {now:%A, %B %d, %Y %I:%M %p}")

def show_tip():
    """Print a random tip."""
    tip = random.choice(TIPS)
    print(f"💡 Tip of the moment: {tip}")

def main(argv=None):
    parser = argparse.ArgumentParser(
        prog="hi",
        description="A minimal everyday assistant you can run from the terminal."
    )
    parser.add_argument(
        "--time",
        action="store_true",
        help="Show the current date and time."
    )
    parser.add_argument(
        "--tip",
        action="store_true",
        help="Print a random helpful tip."
    )
    args = parser.parse_args(argv)

    # No flags → just greet
    if not any(vars(args).values()):
        greet()
        return

    if args.time:
        show_time()
    if args.tip:
        show_tip()

if __name__ == "__main__":
    # Let argparse handle the help flag automatically
    main()
```

### What this script does

| Flag | Behaviour |
|------|-----------|
| **no flag** | Prints a friendly greeting. |
| `--time` | Shows the current date & time. |
| `--tip` | Shows a random, lightweight tip. |
| `-h/--help` | Shows the built‑in help message (handled by `argparse`). |

---

## 2. Make it a real command (`hi`)

Now create a thin wrapper (or a symlink) so you can type `hi` instead of `hi.py`.

### Option A – Symlink

```bash
ln -s ~/.local/bin/hi.py ~/.local/bin/hi
```

### Option B – Bash wrapper

Create a file `~/.local/bin/hi`:

```bash
#!/usr/bin/env bash
exec ~/.local/bin/hi.py "$@"
```

Then:

```bash
chmod +x ~/.local/bin/hi
```

Both approaches let you run `hi` directly.

---

## 3. Ensure `~/.local/bin` is on your `$PATH`

Add the following line to your `~/.bashrc`, `~/.zshrc`, or whichever shell startup file you use:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

After editing, reload the file:

```bash
source ~/.bashrc   # or ~/.zshrc, etc.
```

Now you should be able to type:

```bash
$ hi
👋 Hi! I'm your simple assistant. How can I help you today?

$ hi --time
🕒 Thursday, July 20, 2026 09:45 AM

$ hi --tip
💡 Tip of the moment: Set a timer for 25‑minute work blocks (Pomodoro).
```

## 4. (Optional) Extend the “profile”

If you want the assistant to have a tiny *profile* that can be edited later, you can store a JSON or YAML file alongside the script, e.g. `~/.config/hi/profile.yaml`:

```yaml
name: "hi"
version: "0.1"
author: "Your Name"
greeting: "👋 Hi! I'm your simple assistant."
tips:
  - "Take a short walk every hour to stay refreshed."
  - "Drink water regularly – aim for 8 cups a day."
```

Then modify the script to read that file instead of hard‑coding the strings. This keeps the code clean while giving you a place to tweak messages without touching the code.

4. (Optional) **Add** a separate config file for easy customisation.

**Assistant:** Here’s how you can lock your Mac quickly, using a few different methods:

---

### 1. Keyboard shortcut (the fastest way)

| macOS version | Shortcut |
|---------------|----------|
| **All recent macOS versions** | **Control ⌃ + Command ⌘ + Q** |
| macOS 10.12–10.15 (Sierra–Catalina) | **Control ⌃ + Shift ⇧ + Power button** (or **Control ⌃ + Shift ⇧ + Media Eject** on older models) |
| macOS 10.11 and earlier | **Control ⌃ + Shift ⇧ + Eject** (or the Power button on Macs without an eject key) |

Press the combination once and the screen will go dark, returning you to the login window.

---

### 2. Using the Apple menu

1. Click the **Apple ** menu in the top‑left corner.  
2. Choose **“Lock Screen.”**  
   - If you don’t see it, you can add it to the menu bar via **System Settings → Desktop & Dock → “Show Lock Screen button”** (or “Show fast user switching” on older macOS).

---

### 3. From the Touch Bar (if you have one)

1. Open **Control Center** on the Touch Bar.  
2. Tap the **Lock Screen** icon (looks like a padlock).  

If the icon isn’t there, you can add it in **System Settings → Touch Bar → Customize Control Strip**.

---

### 4. Via the Hot Corners

1. Open **System Settings** (or **System Preferences** on older macOS).  
2. Go to **Desktop & Screen Saver → Hot Corners…**  
3. Choose a corner and set it to **“Lock Screen.”**  
4. Move your cursor to that corner to lock instantly.

---

### 5. Using the command line (for scripts, automation, or remote lock)

Open **Terminal** and run any of the following commands:

```bash
# macOS 10.13+ (uses the built‑in loginwindow)
pmset displaysleepnow          # puts the display to sleep (requires password on wake)
# or
osascript -e 'tell application "System Events" to keystroke "q" using {control down, command down}'
```

You can also lock the screen directly:

```bash
# macOS 10.15+ (uses the lock command)
"/System/Library/CoreServices/Menu Extras/User.menu/Contents/Resources/CGSession" -suspend
```

You could place any of those lines in a shell script or an Automator workflow for one‑click access.

---

### 6. From the Login Window (if you’re already logged out)

If you’re on the login window (e.g., after a restart) and want to lock the screen again, just press **Command ⌘ + Option ⌥ Power** (or **Command ⌘ + Option ⌥ Eject** on older Macs).

---

## Quick tip for extra security
Make sure **“Require password… after sleep or screen saver begins”** is enabled:

1. **System Settings → Lock Screen** (or **System Preferences → Security & Privacy → General** on older macOS).  
2. Set “Require password” to “immediately” (or a short delay).

That way, even if you just let the display sleep, a password will be required to get back in.
