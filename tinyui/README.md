# tinyui

The web UI for `hi`. Vue 3, TypeScript, Vite, Tailwind CSS v4 and [shadcn-vue](https://www.shadcn-vue.com) components
(`src/components/ui/`, generated by the shadcn-vue CLI and edited freely). It talks to the backend in `hi/server/`.

```bash
npm install
npm run dev                         # http://localhost:5173 (the backend only allows this origin)
npx vue-tsc --noEmit -p tsconfig.app.json
npm run build
npx shadcn-vue@latest add <name>    # add another component
```

`VITE_HI_BACKEND=http://127.0.0.1:18765 npm run dev` points the UI at another backend (for testing).

## Layout

```text
src/App.vue                  shell: sidebar + the open view
src/components/app/          sidebar (chats, search, nav), page header, master/detail layout
src/components/chat/         ChatView, TurnView, RunTimeline, ToolCall, ThinkingBlock, AskForm, Composer, voice overlay
src/components/content/      MarkdownContent, MermaidDiagram, CodeBlock
src/composables/             useChat (stream -> turns), useSessions, useVoice, useStatus, useTheme
src/lib/                     markdown segmenting, mermaid loader, run helpers (steps, run diagram)
src/views/                   Inbox, Tasks, Memory, Daily logs, Status, Settings
```

## How a reply is drawn

`useChat` turns the AG-UI event stream into a `Turn`: ordered blocks (thinking, tool calls, text) that each carry the
time they started and ended. `RunTimeline` reads those times to show the steps (choosing an agent, waiting for the
model, thinking, each tool, writing, drawing a diagram) with live timers. Text goes through `MarkdownContent`, which
draws ` ```mermaid ` blocks as diagrams (Mermaid is loaded on first use) and code blocks with a copy button.
**Visualize** in the composer asks the backend to draw a diagram of each answer after it streams.

## Chats

Each chat is a session stored in the vault by the backend (`hi/memory/sessions.py`). The sidebar lists them grouped by
day, with search over titles and what was said, rename, pin, archive and delete.
